# Lineage releases

This repository is the public, release-only home of Lineage builds. It holds:

- the release archives for each supported platform and their `checksums.txt`;
- the version-bound installer `lineage-installer.sh`;
- the release manifests and the promotion and retirement records that
  `lineage` uses to update itself.

It does **not** contain Lineage's source code. GitHub attaches "Source code
(zip / tar.gz)" archives to every release automatically; for this repository
they contain only these release records, not the application source.

Install instructions and documentation: <https://www.lineagent.ai>
